# เพอร์ซิอุส: เควสที่กดยกเลิกไม่ได้ — Treatment

## Brief (สรุป)
- หัวข้อ: ตำนานเพอร์ซิอุส เล่าแบบเกม MMORPG (ไอเทม เควส บอส ปาร์ตี้ ระบบแจ้งเตือน)
- โครงเรื่อง ข. เปิดด้วยฉากบอสแล้วย้อนเล่า · ไม่มีสตอรีบอร์ด
- เสียงพากย์: เครื่องนี้ต่อบริการเสียงไทยออนไลน์ไม่ได้ → ใส่ "เสียงไกด์" espeak-ng (ไทย, ออฟไลน์) ไว้ให้จับจังหวะ
  พร้อมสคริปต์อัดเสียงและคำสั่งสลับเป็นเสียงผู้ใช้เอง (ผู้ใช้อัดเสียงเองอยู่แล้วในเพจ)
- ดนตรี: GitHub Releases (คลังแซมเปิล) ถูกบล็อก → สกอร์สังเคราะห์ทั้งหมด (พิณ Karplus–Strong, สตริงแพด, ฮอร์นสังเคราะห์, ทิมปานี, คอรัสฟอร์แมนต์)

## 1. สามโครงที่พิจารณา
1. **เล่นตามลำดับ**: สร้างตัวละคร → รับเควส → ไอเทม → บอส → จบ ตรงไปตรงมา แต่ 3 วินาทีแรกไม่มีอะไรดึง
2. **เปิดหน้าบอส แล้วย้อน** (เลือก): เปิดในถ้ำกอร์กอน หลอด HP บอส + คำเตือน "ห้ามมองตา" → เฟรมค้าง กรอกลับ → เล่าทั้งเควส
   → กลับมาที่เฟรมเดิมซึ่ง "เปลี่ยนไป" เพราะตอนนี้มีไอเทมครบ → จบด้วยทวิสต์คำทำนาย
3. **หน้าจอโลก (overworld) + แชต**: เล่าผ่านแผนที่กรีกบนโต๊ะ ดำดิ่งลงทีละเมือง ตลกแต่ห่างอารมณ์ตัวละคร

เหตุผลที่เลือก 2: คลิปสั้นแนวตั้งต้อง hook ทันที, การกลับมาที่เฟรมเปิดแบบ "เปลี่ยนไปแล้ว" คือ rhyme ที่สไตล์นี้ทำได้ดี,
และทวิสต์ตอนจบ (เควสคำทำนาย "สำเร็จ" ทั้งที่เขาไม่ได้ต้องการ) ใช้ภาษาระบบเกมพูดเรื่องโชคชะตาได้คมที่สุด

## 2. Logline และ arc
ชายหนุ่มที่เกิดมาพร้อม "คำสาปคำทำนาย" รับเควสฆ่าเมดูซ่าจนสำเร็จทุกอย่าง แต่เควสที่เขาไม่เคยกดรับกลับเป็นเควสเดียวที่ระบบนับว่า "สำเร็จ"
- Setup: บอสที่มองแล้วกลายเป็นหิน / เด็กที่ถูกโยนลงทะเลเพราะคำทำนาย
- Turn: เขาชนะทุกอย่างด้วยการ "ไม่มองตรงๆ" และไอเทมจากเทพ
- Ending: จักรที่ขว้างในงานกีฬาโดนชายแก่ = ตาของเขา → ระบบขึ้น QUEST COMPLETE → ฟ้ามืด ดาวติดทีละดวงเป็นกลุ่มดาวเพอร์ซิอุส

## 3. Benchmark
- เกม JRPG แนว 2D-in-3D ยุค 2018–2023 (กรามมาร์ภาพของสไตล์), และฉากเปิด in-medias-res ของ *Mad Max: Fury Road* (เปิดกลางเรื่องแล้วค่อยอธิบาย)

## 4. ตัวละคร (สไปรต์พิกเซล ~40–56 px)
- **เพอร์ซิอุส**: เสื้อคลุม**แดงชาด** (สีอิ่มสีเดียวที่ไม่มีฉากไหนใช้), ผมดำ, ต่อมามีหมวกบรอนซ์ รองเท้าปีกขาว โล่บรอนซ์ ดาบเคียว
- **ดาเน่** (แม่): ผ้าคลุมฟ้าซีด · **ทารก** ในอ้อมแขน
- **โพลีเดกทีส**: เสื้อม่วงคล้ำ มงกุฎทอง ตัวกว้าง
- **เมดูซ่า**: ผิวเขียวซีด ผมงู (พิกเซลสีเขียวขยับ 2 เฟรม) ตาเรืองเขียว — ใหญ่กว่าฮีโร่ 1.4 เท่า
- **เฮอร์มีส** (หมวกปีก) / **อะธีน่า** (หมวกเหล็กยอดขน + โล่) ยืนเป็นสไปรต์เรืองแสงในวิหาร
- **แอนโดรเมด้า**: ชุดขาว ผมน้ำตาล, **ซีตัส**: สัตว์ทะเลบิลบอร์ดใหญ่ (หัว+คอ) โผล่จากทะเล
- **อะคริเซียส** (ตา): ชายชราเคราขาว เสื้อคลุมน้ำตาล นั่งบนอัฒจันทร์
- **เพกาซัส**: ม้าขาวมีปีก บิลบอร์ดเรืองแสง

## 6. Native move (จุดพีค)
**"ไฟของบอสดับ เงากระโดด"**: เมดูซ่าคือแสงเขียวหลักของถ้ำ ทั้งฉากเงาของทุกอย่างชี้ออกจากเธอ ตอนดาบฟัน
แสงเขียวดับในเฟรมเดียว ความเงียบ 0.8 วิ แล้วแสงขาวของเพกาซัสพุ่งขึ้นจากจุดเดิม เงาทุกเงาเหวี่ยงกลับทิศ
รอง: **ดาวติดทีละดวง** ตอนจบ (lights popping on) และ **ไอเทมเรืองทีละชิ้น** ในวิหาร

## 9. Cue map
- 84 BPM (bar = 2.857 s) ตลอด เพื่อให้คัตลงดาวน์บีตได้ง่าย
- A (0–6): โดรนต่ำ + คอรัสฮัม + ทิมปานี rolling, หยุดดังตอนกรอกลับ (6.0) → reverb tail
- B (7.4–17): พิณ arpeggio เบาๆ (D dorian), แพดสตริง
- C (17–28): ฮอร์นต่ำ + กลองมือ เดินตามจังหวะ 84
- D (28–40): พิณ + เซเลสตา, ไอเทมแต่ละชิ้นลงบีต (ทุก 1.2 วิ ≈ ไม่ล็อกบาร์, ใช้ chime ของ UI เป็นตัวลง)
- A' (40–52.5): กลับธีมถ้ำ เร่งขึ้น tremolo สตริง → ตัดเงียบที่ 51.6
- 52.5: ฟัน (hit) → เงียบ → 53.6 คอรัสเปิดแบบ major (บูมใหญ่ + shimmer)
- E (60–70): ทิมปานี + สตริงเร็ว ostinato ฟ้าร้องตามแฟลช
- C' (70–75): สตริงพิซซิคาโตตลก
- F (75–81): แพดสว่างเบา, หยุดที่ 81.0 (เงียบสนิทถึง 83.5)
- 83.5: ระฆังต่ำ 1 ครั้ง + "fanfare" ของระบบเล่นช้าลงและ minor
- G (88–96): แพด + พิณช้า, ระฆังเล็กทุกดาว, จบบนคอร์ดค้าง
